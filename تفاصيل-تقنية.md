# 👨‍💻 التفاصيل التقنية - REIHA

## 📋 ملخص المشروع

**النوع**: موقع إدارة عطور محلي (Single Page Application)  
**الإطار عمل**: Vanilla JavaScript - لا توجد مكتبات خارجية

function performSearch(query) {
  1. تطبيع الاستعلام → toLowerCase()

## 📷 معالجة الصور

### عملية الضغط

```javascript
function processImage(file) {
  1. التحقق من النوع (JPG, PNG, WEBP)
  2. التحقق من الحجم (≤ 10MB)
  3. تحميل الملف كـ FileReader
  4. رسم على Canvas بحجم أقل
  5. تحويل إلى Base64 (JPEG, quality: 0.75)
  6. حفظ في متغير compressedImage
}
```

### الحدود:
```
الحد الأقصى للحجم: 10MB
الحد الأقصى للأبعاد: 400px
جودة الضغط: 75%
الصيغ المدعومة: JPG, PNG, WEBP
```

## ⚡ تحسينات الأداء

```javascript
// 1. Lazy Rendering
→ الهياكل تُعاد بناؤها عند التغيير فقط

// 2. Event Delegation
→ لا توجد listeners على كل زر (onclick مباشر)

// 3. CSS Optimization
→ استخدام CSS Variables لتجنب التكرار
→ استخدام Grid + Flexbox لتجنب Float

// 4. Image Compression
→ حجم الصورة يصغر من ملايين البايتات إلى آلاف

// 5. localStorage Efficiency
→ DOM parsing وليس polling
```
