# REIHA - Luxury Arabic Perfume Website

A professional, fully-featured Arabic luxury perfume management website with an elegant dark theme and golden accents.

## 🌟 Key Features

### 🔍 Advanced Search System
- Search for perfume names and brand names simultaneously
- Real-time dynamic results
- Emoji indicators for quick visual scanning
- Keyboard shortcuts support (Press Escape to close)

### ✨ Enhanced Error Handling
- File type validation (JPG, PNG, WEBP only)
- File size checking (10MB max)
- Detailed error messages with solutions
- Separate handling for QuotaExceededError
- User-friendly warnings with emojis (✅ ❌ ⚠️)

### 📱 Fully Responsive Design
- 5 responsive breakpoints
- Optimized for all devices:
  - Desktop (1024px+)
  - Tablet Landscape (768-1024px)
  - Tablet Portrait (480-768px)
  - Mobile Standard (360-480px)
  - Mobile Small (< 360px)

### 🎨 Professional Visual Effects
- Smooth cubic-bezier transitions on all elements
- FadeIn and SlideUp animations
- Custom golden scrollbar
- Optimized hover states
- Transform-based effects for performance

### 🖼️ Automatic Image Processing
- Automatic image compression (JPEG, quality: 0.75)
- Smart image resizing
- Base64 encoding for storage
- Preview functionality
- Drag & drop support

### 📊 Complete Product Management
- Add special offers perfumes
- Manage brand sections per mark
- Hide/show products temporarily
- Permanent deletion with confirmation
- Hidden products section

### 💾 Local Data Storage
- All data stored in browser localStorage
- No external servers required
- Offline functionality
- Privacy-focused

## 🚀 Quick Start

1. **Open the website**: Double-click `index.html.html`
2. **Add perfumes**: Fill the form in the Admin section
3. **Search**: Use the search bar at the top
4. **Browse brands**: Scroll through each brand section
5. **Manage**: Hide, show, or delete products as needed

## 📝 Usage Tips

### Best Practices for Images
- Use high-quality source images
- White or neutral backgrounds work best
- Good lighting is important
- Bottle should fill most of the frame

### Efficient Management
- Use clear perfume names
- Follow pattern: name - size - price
- Hide products not ready for sale
- Update quantities regularly

### Effective Searching
- Type key words (not full names)
- Case-insensitive search
- Works for both names and brands

## ⚠️ Limitations

- localStorage size limit (typically 5-10MB)
- No real-time sync between devices
- Local browser only (not accessible from other devices)
- Data lost if browser cache is cleared
